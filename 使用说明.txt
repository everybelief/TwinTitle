工具名称：TwinTitle（同题猎手）
本目录即可运行。测绘 / 探活 / 备案走 tools\ 随包文件。

启动
  1. Python 3.8+（带 tkinter）
  2. pip install -r requirements.txt
  3. 双击 启动.bat，右上角「配置」填 FOFA Key
  4. 也可手改 config.json

必填：公司名称（全称，一行一个可批量）
可空：官网根域 / URL / 别名 / 关键字
结果按公司、按判定分类。导出 xlsx 到 out\

步骤：备案反查根域 → 探官网标题 → FOFA 精确/关键字 → 改后缀看是否注册
反查走 https://icplishi.com/company/公司全称/
Clash 198.18 假 IP 不算存活。官网只留一条活体。

判定：可疑钓鱼 / 可疑-被拦 / 可疑-不通 / 需人工 / 测绘过期 / 博彩/冒备案 / 自有 / 排除

Hunter / Quake / WHOIS 不做。
